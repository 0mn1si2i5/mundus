# Desktop render baseline · 2026-07-14

Historical baseline: this report preserves measurements of the implementation and hardware tested on 2026-07-14. Its pass statement applies to that run; it does not establish the current version's performance or complete a new release gate. Re-measure the intended release on its target hardware.

## Method

- Production build served with `pnpm preview`
- Headed Chrome 147, 1440 × 900 viewport, DPR 1
- WebGL renderer: `ANGLE Metal Renderer: Apple M5 Pro`
- Quality profile: `high`
- 2 seconds warm-up followed by 10 seconds of actual R3F render-frame sampling
- Scene kept in its initial slow rotation; no user input during sampling

The benchmark is enabled only by `?benchmark=1`. It records frames inside R3F's `useFrame`, not generic page animation callbacks.

## Hardware

- MacBook Pro with Apple M5 Pro
- 18 CPU cores, 20 GPU cores, 48 GB memory
- 60 Hz external display

## Result

| Metric            |    Result |
| ----------------- | --------: |
| Frames            |       601 |
| Duration          | 10,000 ms |
| Average FPS       |      60.0 |
| Frame time p50    |   16.7 ms |
| Frame time p95    |   17.5 ms |
| Longest frame     |   18.0 ms |
| Frames over 25 ms |        0% |

Desktop gate: **pass**. The observed rate reaches the 60 Hz display ceiling and satisfies the planned 45–60fps range.

Evidence screenshot: `output/playwright/desktop-benchmark.png` (local, intentionally ignored by Git).

## Reproduce

```bash
pnpm build
pnpm preview --host 127.0.0.1
```

Open `http://127.0.0.1:4173/?benchmark=1`, keep the tab visible and idle, then read the result after 12 seconds. The structured result is also available at `window.__MUNDUS_BENCHMARK__`.

## Mobile follow-up

No online physical phone was available during the desktop run. A subsequent physical iPhone 17 result is recorded in [2026-07-14-iphone-17.md](2026-07-14-iphone-17.md). The planned mid-range-device sample remains separate.

For the phone run, serve the production build on the LAN with `pnpm preview --host 0.0.0.0`, open `http://<computer-lan-ip>:4173/?benchmark=1` on the physical phone, keep the page foregrounded and idle for 12 seconds, then record the visible FPS/p95 result together with device model, OS, browser and screen refresh rate.
