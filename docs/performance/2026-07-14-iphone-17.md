# Physical mobile render baseline · 2026-07-14

Historical baseline: this report preserves the operator-reported result from 2026-07-14. Its pass statement applies to that implementation and device; it does not establish the current version's performance or complete a new release gate. Re-measure the intended release on its target hardware.

## Device and method

- Device: iPhone 17, model `MG6W4CH/A`
- OS: iOS 26.5.2
- Browser: Chrome
- Quality profile: `low`
- Production build served over the local network
- Default benchmark: 2 seconds warm-up followed by 10 seconds of actual R3F render-frame sampling

The result was read from the benchmark panel on the physical phone and reported by the device operator. A structured browser payload was not exported for this run, so only the displayed metrics are recorded.

## Result

| Metric          |  Result |
| --------------- | ------: |
| Average FPS     |    60.0 |
| Frame time p95  | 17.0 ms |
| Quality profile |     low |

Physical mobile low-profile baseline: **pass**. The result is comfortably above the planned 30fps floor.

## Gate qualification

This run proves the real-phone `low` quality path, touch-sized viewport path and production network delivery can sustain the display-rate ceiling on the tested iPhone 17. It is not labeled as the planned mid-range-device sample; that separate hardware-representativeness check remains open.
