# Mundus

[English](README.md)

Mundus 是一颗长期维护的个人数字地球，用不同科学视角观察同一颗行星。它被设计为一件小型数字博物馆展品：容易上手，明确说明方法，也诚实呈现数据边界。

当前实现包含五个观察模式。地球另一端、姓氏观察、城市邻近性和变形地球是主要观察；日照线仍放在“更多观察”中：

- **地球另一端（Other Side）**：计算精确起点与对跖点，并分别显示捆绑 GeoNames 快照中距两端最近的符合条件主要城市。结果是收录主要城市，不代表最近聚居地、行政边界或建成区。
- **姓氏观察（Surname Atlas）**：凡有国家级来源记录的国家都会在地图上显示一个姓氏字标——有数字排名时为 rank=1 姓氏，否则为来源列出或人工整理的常见姓氏，并在结果面板中注明类别。字标可切换为当地文字、拉丁字母转写或中文（Mundus 审校的译名）。字标限定在本国范围内，狭长国家会沿国土走向旋转。它使用社区快照，不是统一的官方全球排名；缺失字段会明确显示；结果面板链接每个国家的来源，数据集许可见“关于”。
- **城市邻近性（Urban Proximity）**：用可调的规模门槛 α，显示最近一座足够大的 GHSL 城市中心及阶梯式邻近距离。距离是城市中心点之间的大圆距离，不代表交通可达性。全球分区视图按距离除以中心当前邻近距离的规则分配陆地，各区域有自己的中心。
- **日照线（Sunline）**：以 UTC 展示昼夜分界，并估算太阳位置、日出和日落；结果仅用于教育展示。
- **变形地球（Reshaped Earth）**：改变国家面积，比较 2020 年人口、PPP GDP、化石 CO₂ 和夜光。斜线区域标示连续变形无法去除的多余面积，实色核心代表应得面积；分享的地点始终保留真实坐标。来源、缺失值与数值精度见[方法说明](docs/data/reshaped-earth.md)。

## 本地运行

可复现的数据与发布门禁使用 Node.js 22.23.1，以及 pnpm 11.7.0。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

提交修改前运行完整本地门槛：

```bash
pnpm check
pnpm test:e2e
```

`pnpm check` 会检查格式、lint、类型、生成数据完整性、单元测试和生产构建。V1 的公开生产产物明确不发布 source map。

产品使用可复现生成的 Natural Earth 矢量球面：低画质加载 110m，中/高画质加载 50m；国家颜色来自小型调色板纹理，原有栅格地球继续作为加载与失败回退。

## 数据与许可证

仓库中的 MIT License 只覆盖 Mundus 源代码。内置数据集和第三方软件包继续适用各自的条款。数据版本、转换、署名和局限见[数据来源](DATA_SOURCES.md)，依赖与数据许可证清单见[第三方许可证](THIRD_PARTY_LICENSES.md)。

Natural Earth 边界是制图表达，不是领土状态的法律权威。太阳计算结果属于教育性解释，不得作为法律、航海或工程依据。

## 仓库结构

```text
src/
  app/           应用外壳与响应式布局
  data/          数据清单、生成快照与注册表
  features/      地球内核与按领域组织的观察模式
  i18n/          中英文界面文案
  state/         小型跨功能状态
  styles/        全局令牌与基础样式
  test/          单元测试环境
tests/e2e/       真实浏览器发布检查
tests/release/   线上部署冒烟测试
scripts/         离线数据构建与发布校验
docs/            产品决策与实施证据
.github/         CI 与 GitHub Pages 工作流
```

Mundus 是纯静态浏览器应用，共用一个三维地球，没有后端或数据库。架构和模式契约见
[项目计划](docs/PROJECT_PLAN.md)。`src/data/generated/` 同时包含运行资产和离线重建的
不可变输入，它们是受跟踪的发布输入。原始下载、研究图片和本地测试证据放在工作树外；
依赖和可重建的构建/测试输出由 Git 忽略。

安全问题请按 [SECURITY.md](SECURITY.md) 私密报告。
